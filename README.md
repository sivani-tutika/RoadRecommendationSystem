# Road Recommendation System
## This project is part of CSCE 5210: Fundamentals of AI. 

## Introduction

To understand the fundamentals of an Artificial Intelligence system, the project focuses on brute force approach of solving problems rather than learning i.e. Machine Learning. As part of this project we first generate a network of connected roads and also the traffic in those roads. Then you think from a point of view of a builder, city manager and try finding which new roads would benefit the most based on existing data.

## Installation

No installation needed. 
1. Open the Colab file directly via this [link](Pair_14_project1_partB.ipynb)
2. Run each cell in the notebook sequentially.

## Usage
The notebook is organized into several section:
- **Network Setup:** Defines the initial road netwrok in the city.
- **Traffic Simulation:** Simulates the trafic flow randomly on the network of roads.
- **New Road Recommendations:** Uses brute force that is fundamental of AI to recommend new roads.
- **Scalable solution:** Scaling the solution to large amount of roads.
